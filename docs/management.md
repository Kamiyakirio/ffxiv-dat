# 肖像与资料夹管理

应用默认打开「肖像管理」。「高级解析」保留原有的 DAT 解码、逐层浏览、技术数据和字段编辑。

## 肖像管理

选择角色后可搜索、多选肖像，查看动作、背景、装饰、镜头、视线、灯光和套装关联。

- **跨角色复制**：勾选来源角色的肖像，点击「复制肖像」；切换到目标角色，点击「粘贴到此角色」，选择新建或覆盖。
- **导出分享码**：选择一个或多个肖像，点击「导出分享码」。可直接复制完整代码；系统剪贴板不可用时仍可手动复制。
- **导入分享码**：粘贴后点击「读取分享码」，检查数量并选择新建或覆盖。批量覆盖按目标的勾选顺序与导入记录对应。
- **名称与删除**：在详情中修改动作自定义名称；多选后可批量删除。删除会解除相应的本地套装肖像关联。

新建使用空闲的物理槽位，最多 110 个；覆盖保留目标槽位。分享完整保留肖像记录的字段字节，仅在导入时替换物理槽位编号。角色外观、装备和已解锁内容仍由目标角色决定，工具不渲染游戏内的三维肖像。

写入前请退出游戏。每次修改前都会备份整个角色资料夹；如果文件在读取后发生变化，会要求刷新，避免覆盖游戏或其他程序的修改。

### 分享协议 v1

分享码为没有可见前缀的单段 Base64url 文本，不含角色目录、Content ID 或完整装备数据。

1. JSON 内容为 `{ "version": 1, "records": ["…"] }`。每个元素是单条完整肖像记录的 Base64url 数据，其中物理槽位编号归零。
2. JSON 使用 UTF-8 编码，经 raw DEFLATE 压缩。
3. 在压缩数据末尾追加其 SHA-256 的 32 个原始字节，再对整体进行不含填充的 Base64url 编码。

导入先检查完整性，再解压和验证版本与字段边界。SHA-256 用于检测截断或改动，不用于认证分享者。输入最多 256 KiB，解压最多 1 MiB，一次最多 110 个肖像；不完整或包含未支持字段的记录会被拒绝。

## 资料夹备份

默认备份目录为所选游戏配置目录的同级目录 `FFXIV DAT Backups`。通常为：

```text
My Games/
  FINAL FANTASY XIV - A Realm Reborn/
    FFXIV_CHR<16 位十六进制角色 ID>/
  FFXIV DAT Backups/
```

可以更改备份位置，选择会保存在应用设置中。切换位置后显示新位置的备份，原位置中的备份不会被移动或删除；切回原位置可继续管理。

可勾选多个角色进行备份。每份备份记录角色、源目录、创建时间、文件数量、总大小和来源（手动备份、肖像修改前、还原前）。备份包含整个角色资料夹的文件和空目录，包括日志。不会跟随符号链接。

还原时先校验备份的所有文件，再自动备份当前资料夹，最后替换整个资料夹。备份时间之后新增的文件也会随整个目录的还原而移除，可以从还原前的自动备份恢复。备份只能还原到原配置目录中的同一角色。

删除备份需要确认，删除后无法从应用中撤销；这不会修改游戏资料夹。备份损坏时会保留文件并显示提示，不会用损坏数据覆盖角色资料夹。
