# DAT 解码器

主进程入口：`src/main/services/dat/decoder.ts`。

```ts
const result = decodeDat(bytes, filename);
```

输入原始 `Buffer` 和文件名，返回：

- `header`：类型、版本、有效长度等文件头信息。
- `payload`：解除已知 XOR 后的有效字节。
- `result`：解析状态、结构化数据和警告；失败原因在 `data.parseError`。
- `members`：备份文件中的内嵌配置及其偏移。
- `sha256`、`checks`：源字节摘要和可执行的身份核对。

支持角色配置 DAT、共享宏、外观预设、配置复制记录及配置备份。
解析器只处理传入的字节，不读写磁盘；64 位 ID 使用字符串保留精度。

`decoded` 表示已实现的布局与字段解释完成；`partial` 表示仍有候选解释或未知业务字段；
`unsupported` 表示没有适用的解析器。具体缺口由每个文件、子段的 `coverage` 列出；
原始字节和偏移保留，游戏 ID 不保证都有名称。

字段参考 FFXIVClientStructs `b72bc1f73`。本轮进一步静态核对指定中国客户端 EXE，
SHA-256：`958b78e278ad896493c484eb313ff605ab41edefef74f92b0ee078e69b281bf9`。
方法为 PE 布局检查与 Apple LLVM 反汇编，未执行游戏；各模块注释保留读写器及消费者地址。
REA 段布局证据：`ev_274525b6af70778a8262380c9f8a383e10ddccda35739a263829eedd7e9719ef`。

本轮补全或纠正：

- 肖像的变长旗标、索引、环境光/方向光、名称对齐，以及 92 字节装备快照的 CRC-32 校验。
- 青魔法预设的分列存储、技能与宏位图、个人/公用宏编码和最近技能。
- 集体动作镜头参数、相对 XYZ 与坐标系；去除把向量对齐字节当作 W 的编辑项。
- 表情的两位状态、技能变换设置、物品菜单文字/显示许可/默认顺序。
- 社交子块与列式名单、跨服通讯贝在线成员优先、雇员探险完成时间及固定历史记录。
- 麻将设置及已查看位图、贴纸位置/旋转/颜色/文字参数、快捷面板设置与图标来源。

名称参考保存在 `native-save-data.json`。本轮没有重新取得匹配的 SqPack，新增公开表文字固定于
`thewakingsands/ffxiv-datamining-cn` 的 `2c6741cffe3cfe70f093c54c463791364e515d8d`；
未验证为目标资源表的 PvP、青魔法等关联保持候选标记。

尚未完全解释：社交列表的部分身份/状态及两个子块、通讯贝后续区域、麻将私有设置及历史数值用途、
贴纸图片子类及一项 UI 设置、相机内部参数与灯光枚举名、未命名 UI 旗标和雇员任务编号的资源表关联。
肖像装备校验未匹配不等于文件损坏：幻化板和运行时有效性判断可能参与生成校验输入。

验证包括合成数据的完整容器解码、可读视图及编辑字节保留回归，以及真实配置的只读核对。
